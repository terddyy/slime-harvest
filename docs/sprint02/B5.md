# B5 - Orchard + fruit trees (done)

## What changed
- New `scripts/orchard.gd` (`class_name Orchard`, Node2D). Trees live in the `orchard` area of `WorldLayout`.
  `Orchard.TYPES` (apple, cherry, peach, pear: name, sapling_price, fruit_price, texture). Growth is by day:
  sapling -> young (`YOUNG_DAYS`=1) -> grown (`MATURE_DAYS`=3), then fruit every `FRUIT_DAYS`=3 days, `FRUIT_PER_TREE`=3 per picking.
- API: `plant(cell, id)`, `can_plant(cell)`, `harvest(cell) -> id or ""`, `has_fruit`, `has_tree`, `stage`, `tree_count`, `new_day()`,
  `to_save/from_save`. Main calls `new_day()` at dawn (`_on_phase_changed(false)`), sets `area` and `tree_parent`.
- Game: `saplings`, `fruit_in_bag` (dicts by tree id), `buy_sapling`, `sapling_count`, `use_sapling`, `next_sapling`, `add_fruit`,
  `bag_total()` (crops + fruit). `bag_value()` and `sell_crops()` include fruit. HUD bag count and shop sell row use `bag_total()`.
- Shop: four sapling rows in the right column (ids `sapling_<tree>`).
- Main: E on the target cell picks fruit, or plants the first sapling you own (hint text shown).

## Save data
- section `orchard`: `{"trees": [[x, y, {id, age, wait, fruit}], ...]}` (registered in `Main._register_save_systems`).
- section `game`: new keys `fruit_in_bag`, `saplings` (old saves load fine, both default empty).

## Gotchas
- Trees are static bodies in `Entities`; the `orchard` area is in `farm.blocked`, so nothing else is planted there.
- Mature tree without fruit uses the generic stage-3 frame; the per-type sheet is only shown while it has fruit.
- Fruit icons in the shop are small and the cell mapping (apple 1, pear 2, peach 3, cherry 4) is a guess from the picture.
- Prices are placeholders for P1.
