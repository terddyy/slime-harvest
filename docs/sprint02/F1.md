# F1 - Remove survival (done)

## What changed
- Player: no HP, no hurt/knockback/blink, no death. `health_changed` and `died` signals,
  `hp`, `is_dead` (its last reader in `Main._interact()` was fixed too), `take_damage()`, `heal()`, `get_max_hp()`, `MAX_HP` are gone.
- Slime: only targets crops (nearest one) and fences in the way; ignores the player and has no
  `player` field, no `damage` stat, no `CHASE_RANGE`/`RECOIL_SPEED`. With no crops left it idles.
- Skeleton + projectile scripts deleted; `"skeleton"` removed from `Waves.KINDS` and the wave
  table (their slots became extra medium slimes, same enemy totals per night) and from `Spawner`.
- Shop: "hearts" upgrade and "Heal to full" removed (`Game.UPGRADE_PRICES` = sword, can only;
  `Game.HEAL_PRICE` gone). `Shop.player` removed. `Game.spend()` kept for one-off purchases.
- HUD: HeartBar removed. Feedback: hurt shake removed (`Effects.shake` still exists, unused).
- `lose.wav` and `player_hurt.wav` deleted, also from `tools/gen_audio.py`.
- `Game.game_ended` has no argument now (was `won: bool`) and `Game.end_game()` takes none.
  The end screen is only the "You survived N nights!" screen for now; F2 replaces it.
- Tests updated (run_tests, playthrough no longer tracks hits/hearts, aim_test has
  `_test_no_survival`). GDD, ASSETS, CLAUDE.md, How to Play text updated.

## Still true / for later tickets
- `Game.NIGHTS_TO_WIN` and the end-of-night-7 win are still there; F2 removes them.
- The tutorial text needed no change (it never mentioned hearts).
- Skeleton sheet layout stays documented in `docs/ASSETS.md` (unused art).
- No save data added.
