# B2 - Farmhouse interior + sleep (done)

## What changed
- `scripts/farmhouse.gd` (`Farmhouse`, created by Main, `setup(player, camera, farm, fences, hud, entities)`):
  door on the farm side at `Farmhouse.door_cell()` (bottom-middle cell of `farmhouse_plot`), a 12x7 room drawn at
  `ROOM_ORIGIN` (4000, 0) far off the map, bed, bookshelf, exit door. E = `interact()`, HUD text = `hint()`.
  Entering fades, moves the player, swaps `walk_bounds` and camera limits, and back out restores them.
  `is_inside` is read by Main (no night tint, no tile cursor, hints).
- Sleep: E at the bed. Allowed at night or when the day is >= 50% done; else "Too early to sleep". Fade, crops
  eaten (30% each, only those not enclosed by fences), `Game.sleep_to_morning()` (day+1, morning, emits
  `phase_changed(false)` so Main clears enemies, shows banner and auto-saves), banner "slimes ate N crops".
- `scripts/sleep_rules.gd` (`SleepRules`): `can_sleep`, `is_enclosed`, `eaten_crops` (pure, tested).
- Added: `Game.sleep_to_morning()`, `Farm.crop_cells()`, `Player.save_position_override` (set while indoors so a
  save stores the spot outside the door).
