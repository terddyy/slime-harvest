# F4 - New map layout framework (done)

## What changed
- Map is 80x50 tiles (was 48x30), described as data in `scripts/world_layout.gd` (`class_name WorldLayout`).
  `Main` now builds the world from it; the old `_build_ground`, tree scatter and stall footprint loop are gone.
- New `scripts/ground_builder.gd` (`GroundBuilder.build(ground)`): paints grass + tufts, dirt paths and ponds
  into the `Ground` TileMapLayer (3x3 rectangle autotile via `WorldLayout.edge_tile`).
- Ponds block walking (one StaticBody2D with a box per pond, `Main._place_ponds`), rocks are small obstacles.
- `Main.MAP_SIZE` / `STALL_CELL` still exist (aliases of the layout constants). Player starts at `WorldLayout.PLAYER_START`.

## WorldLayout API (all static, pure data, tested without Game)
- Constants: `MAP_SIZE`, `PLAY_AREA` (Rect2i given to `farm.bounds`), `PLAYER_START`, `STALL_CELL`, `STALL_FOOTPRINT`,
  `FIELDS`, `PLOTS`, `PONDS`, `PATHS`, tree/rock counts + seeds.
- `area(name)`, `area_names()`, `area_at(cell)`, `is_water(cell)`, `is_path(cell)`, `blocked_cells()`,
  `border_trees()`, `scatter_trees()`, `scatter_rocks()`, `edge_tile(cell, in_set)`.
- Areas (Rect2i, cells): fields `home_field` (24,18,20,14), `south_field`, `east_field`; plots `barn_plot` (8,6,10,8),
  `farmhouse_plot` (28,6,10,8; door = bottom middle, faces the main road at y=14), `well_plot`, `greenhouse_plot`,
  `windmill_plot`, `coop_plot`, `pen_cows`, `pen_chickens`, `orchard`. Pond (10,36,10,8). Paths: main road y=14-15,
  west and east roads x=22-23 / 44-45, stall plaza.
- Plot / pen / orchard / pond / path / stall cells are in `farm.blocked` (not tillable, no fences). Phase 2: put
  your building, animals or trees inside your own area only; if you need collision, add your own StaticBody2D.
  When a restored building should let the player till right next to it, nothing more is needed (plots stay blocked).

## Save data
None added. Gotcha: old (F3) saves keep working, but crops/soil/fences on cells that are now blocked (plots, paths,
pond) or outside `PLAY_AREA` are silently dropped on load, and the player position is clamped to the new walk bounds.

## Gotchas
- Slimes have no collision, so they walk over ponds and plots (like they always ignored trees).
- Spawner spawns on the map edge of the bigger map: slimes take longer to reach crops. P1 balances this.
- Pond is a plain rectangle (tileset only has a rounded 3x3 block). Water is static (animated sheet unused).
- Dirt path joints are not smoothed (no inner-corner tiles used), so T junctions look slightly squared.
- Scattered trees only grow on open ground, so they cluster in the east/south/west margins.
