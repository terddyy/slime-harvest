# F3 - Save system (done)

## What changed
- New autoload `SaveGame` (`scripts/save_game.gd`, after `Game` and `Audio` in project.godot).
  Single file `user://save.json`: `{"version": 1, "sections": {key: Dictionary}}`. Written to a
  `.tmp` file then renamed. Missing, unparsable, non-object or other-version file = no save.
- Save contract: any node with `to_save() -> Dictionary` and `from_save(data: Dictionary)`
  registers with `SaveGame.register(key, node)`. Load order = registration order.
  **Later tickets: register your system in `Main._register_save_systems()` and add your own
  `to_save/from_save`. Keep old keys readable (bump `SaveGame.VERSION` only for breaking changes).**
- `SaveUtil` (`scripts/save_util.gd`): `number`, `list`, `dict`, `is_entry`, `counts`. Use them in
  `from_save` so damaged/hand-edited files can't crash the game.
- Registered by `Main`: `game`, `farm`, `fences`, `player`, `camera` (Game first, farm before fences).
- Auto-save: at dawn (`Main._on_phase_changed(false)`), `PauseMenu` "Quit to Title", and
  `NOTIFICATION_WM_CLOSE_REQUEST` (only while Main is registered; `Main._exit_tree` unregisters, so the
  title screen never saves).
- Title: Continue (visible only if `SaveGame.has_save()`, focused by default) and New Game
  (replaces Start; confirm panel "Delete your saved game and start over?" when a save exists).
  Continue does `Game.reset()`, sets `SaveGame.load_requested = true`, loads main; `Main` calls
  `SaveGame.load_game()` at the end of `_ready`, hides the tutorial, banner "Welcome back - Day N".

## Public API
`SaveGame.path`, `load_requested`, `register(key, node)`, `unregister_all()`, `save() -> bool`,
`read() -> Dictionary`, `has_save()`, `delete()`, `load_game() -> bool`.
New `to_save/from_save` on: `Game`, `Farm`, `Fences`, `Crop`, `Player`, `CameraZoom`.

## Save data (sections)
- game: day, time_left, gold, seeds, crops_in_bag, upgrades, fence_pieces, restored (array of ids).
  A night is saved as `is_night=false`, `time_left = Game.NIGHT_RESUME_TIME` (3 s), so loading
  never needs to restart a night wave. Loading never emits `farm_restored`.
- farm: soil `[[x, y, wet], ...]`, crops `[[x, y, {id, stage, bites, wet_ticks}], ...]`.
- fences: `[[x, y, hp], ...]`.
- player: x, y, facing, tool, seed. camera: zoom.
- Not saved: enemies/spawner state, tutorial progress (a loaded game hides the tips), seed/tool HUD
  is refreshed through the normal signals.

## Gotchas
- Tests that run the game as a scene (aim_test, playthrough) set `SaveGame.path` to a
  `user://test_save_*.json` file and delete it, so dawn autosaves never touch the real save.
  Any new scene-based test that runs a full day must do the same.
- `SaveGame` calls nodes with `.call("to_save")`; it has no reference to `Game`, so it compiles under `--script`.
- Pause menu "Restart" does not delete the save; it is overwritten at the next dawn.
- Farm/Fences `from_save` skip entries outside `bounds`/on blocked cells, so when F4 changes the map
  bounds, saves with cells outside the new bounds silently lose those cells.
