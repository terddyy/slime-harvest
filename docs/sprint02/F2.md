# F2 - Endless days + restoration goal (done)

## What changed
- `Game.NIGHTS_TO_WIN`, `Game.is_over`, `Game.end_game()` and the `game_ended` signal are gone.
  Days never end; nothing pauses the clock. Everything that read them was updated (Hud,
  PauseMenu, Tutorial, Main, Spawner, How to Play text, playthrough).
- HUD clock reads "Day N  Day/Night" (no "/7"). New "Farm n/N" label under the time bar.
- The old "You survived" end screen and its R / T keys are replaced by the ending screen below.
- `Waves.wave(night)` is endless: nights 1-7 use `Waves.NIGHTS`, later ones come from
  `Waves._scaled()` (more slimes, shorter interval, capped at `MAX_EXTRA_NIGHTS` = 20 past night 7).

## New files
- `scripts/restoration.gd` (`class_name Restoration`): `PROJECTS` (array of `{id, name, cost, unlocks}`),
  `project(id)`, `ids()`, `total_cost()`. Ids: well, farmhouse, chicken_coop, barn, windmill, greenhouse.
  Costs (80/150/200/350/500/650) are placeholders for P1. B1 should read this list for the board.

## Public API (Game autoload)
- `Game.restored: Dictionary` (id -> true), `is_restored(id)`, `restored_count()`, `all_restored()`.
- `Game.restore(id) -> bool`: pays the cost; false if unknown id, already done, or too poor.
- Signals: `project_restored(id)` (HUD shows "<Name> restored!" banner) and `farm_restored`
  (emitted once, on the last project). On `farm_restored` the HUD pauses the tree and shows
  "The farm is saved!" with Credits / Keep playing / Quit to Title. Keep playing unpauses.
- `Game.reset()` clears `restored`.

## Save data
None added yet. F3 must save `Game.restored` (keys of the dictionary). Loading a save with
every project restored must not re-emit `farm_restored` (set the dictionary directly).

## Gotchas
- Nothing in the game calls `Game.restore()` yet; the board is B1. Tests cover it.
- The ending screen also uses the existing `Credits` panel; it shows over the tree pause.
- `Audio.stop_music()` is no longer called on the ending (music keeps playing).
- Playthrough bot stops after `NIGHTS_TO_PLAY` (7) nights via its own check; it doesn't restore anything yet (P1).
