# A1: Logo, title art, icon

What changed
- Generated and added `assets/generated/logo.png` (160x78, transparent), `icon.png` (256x256) and their
  `*.prompt.txt` files.
- `tools/process_generated_art.py`: keys out the magenta background of the logo render, crops, Lanczos-downscales;
  also downsizes the icon. Raw renders live outside the repo (Pillow is installed).
- `scripts/title.gd`: the text title is now a `TextureRect` with the logo; tagline kept, placed under the logo.
- Icon: `project.godot` `config/icon` and `export_presets.cfg` `application/icon` point at `assets/generated/icon.png`.
  Old `assets/icon.png` (+ .import) deleted and its `.gitignore` lines removed.
- Docs: ASSETS.md "Generated art" section, CLAUDE.md layout line.

Testing: unit tests (1032 checks, 0 failed), aim test, title and main smoke runs show no SCRIPT ERROR (only the
known "resources still in use" shutdown lines). Title screenshot checked at 960x540.

Known limits
- No separate title illustration (the pack backdrop already fills the screen); skipped on purpose.
- Logo is a ~10x downscale of the render, so letter edges are slightly soft. A2 can reuse `logo.png` for the splash.
- First icon render attempt failed with a Codex error (no image), the logo needed one retry after a hang; each asset has 1 image.
- Web favicon comes from `html/export_icon`, not re-tested here (A2 touches the web shell).
