# B4: Story, intro and ending

What changed
- `scripts/story_panels.gd` (`StoryPanels`, CanvasLayer): picture (320x180, framed), text box, "n / N" counter. Click, interact key,
  Space/Enter go on, Esc skips the rest. It takes input in `_input`, so Esc never reaches the pause menu. The `INTRO` and `ENDING`
  lists (3 panels each, image path + text) are at the top of the file.
- `scripts/credits_roll.gd` (`CreditsRoll`): scrolling credits (about 25 s, any of the same keys skips). Text from the new
  `Credits.roll_lines()`, so names stay in `Credits`.
- Intro: `Main._start_new_day_one()` plays it on a new run before the "Day 1" banner (`Hud.play_intro`). `Game.intro_seen` is set
  when it starts, saved in `to_save()` and read back with default true (old saves skip it). `Game.reset()` clears it, so Restart
  from the pause menu shows it again.
- Ending: `Hud._on_farm_restored` now runs ending panels, then credits, then the old "The farm is saved!" screen (Credits / Keep
  playing / Quit to Title).
- Art: six gpt-image renders in `assets/generated/story_*.png` with `story_*.prompt.txt` (shared preamble describing both
  farmers from the game sprites), downscaled by `tools/process_story_art.py`. Each asset rendered once; all six read and kept.
- Tests set `Game.intro_seen = true` before instantiating main (`aim_test.gd`, `playthrough.gd`).
- Docs: GDD (ending and intro), CLAUDE.md layout, ASSETS.md generated art.

Testing
- `run_tests.gd`: 1215 checks, 0 failed (new `_test_story`: panel counts, images exist, text length, credits lines).
- Aim test passes; playthrough (defend) saved the farm on day 17; title and `main.tscn` smoke runs only print the known
  "resources still in use" shutdown line.
- Staged scene screenshots read at 960x540: intro panel 1, ending panel 2, scrolling credits, final ending screen.

Known limits
- Panels are static text (no typewriter effect), no music change during the story.
- Running the parallel gpt-image jobs at once returned the same image for several outputs (the script picks the newest file), so
  the renders were done one after another.
- Esc during the ending panels skips to the credits, not straight to the end screen.
- The `intro_seen` flag is only written when the game saves (dawn, pause menu, close); quitting with no save in the first day
  means the next New Game shows the intro again, which is intended.
- Not tested in a browser build.
