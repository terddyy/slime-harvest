# C2: Lobby + remote players

What changed
- Title: "Play Together" -> `Lobby` (`scripts/lobby.gd`). Host: name, "Host a Farm" shows the room code, who joined, and Start
  (continues the host's save if there is one, else a new farm). Join: code + name, then "Waiting for the host to start...".
  Errors (`Net.failed` text, "The host closed the room.") show on the page the player is looking at. Esc / Back leaves the room.
  `UiStyle.make_theme()` now styles `LineEdit`. The title menu column uses separation 1 so seven buttons fit.
- Flow: host Start -> normal farm load. When the host's `Main` is built, `CoopSession` calls `Net.announce_start()` (new RPC `_go` in `Net`,
  signal `game_start`; also sent to anybody who joins later). Joiners load `main.tscn`, their `CoopSession` asks the host for the farm
  (`_request_snapshot`, retried 6 x 1.5 s), the host answers with `JSON.stringify(SaveGame.snapshot())`, the joiner applies it with
  `SaveGame.apply()` minus the `player` and `camera` sections (`CoopRules.joiner_sections`). Joiners get a "Getting X's farm..." cover until then.
- `SaveGame`: new `snapshot()`, `apply(sections)` (load_game uses it) and `write_enabled`. A joiner sets it false, so `save()` (dawn, pause menu, close)
  never writes; `unregister_all()` turns it back on.
- Remote farmers: `RemoteFarmer` (same sprite layers as `Player`, shirt tinted per slot by `CoopRules.tint`, name tag, glides toward the last position).
  Everyone sends position/facing/animation at 15 Hz to the host (`_report_state`, unreliable); the host validates it (`CoopRules.clean_state`: clamp to
  the world incl. the farmhouse room, known facing and animation) and forwards to the other joiners (`_show_state`). Joiners only talk to the host.
- Banners "X joined" / "X left". Host leaves or the relay drops a joiner: banner + cover with the reason, title after 2.5 s (`Game.go_to_title()` now calls `Net.leave()`).
  If the host's own relay connection drops, the host gets a banner and plays on alone.
- Online `Main`: host skips the story intro (it pauses the tree); only the host spawns slimes; a joiner hides the tips (restored on exit) and freezes Gayle
  (host-simulated); a joiner starts offset from the host's start spot. Pause menu hides Restart online. `Player.current_anim()` added.
- Tests: `run_tests.gd` +14 checks (CoopRules, snapshot/apply/write_enabled; 1237 total). `tests/coop_test.tscn` (13 checks, 3 processes + relay): two joiners
  get the host's gold and tilled soil, never write a save file, see each other's farmers at the right spot, a leaving player's farmer is removed,
  the staying joiner gets "The host left". Run it 3 times, all green.

Testing: unit 1237/0 failed, net_test 40/0, coop_test x3 green, aim test passes, title and main smoke runs clean (only the known shutdown lines),
playthrough defend saved on day 15. Screenshots (title with 7 buttons, lobby pages, three remote farmers) checked in $TEMP/sh_sprint3/c2. All processes killed.

Known limits (for C3/C4)
- No world sync yet: a joiner's tools only change its own screen; clock, crops, Gayle, animals, orchard and sprinklers are simulated locally on joiners after
  the snapshot and will drift. C3 replaces this with intents and broadcasts.
- Panels and the pause menu still pause the local tree (C3 changes that online). Sleeping does not wait for everyone.
- Remote farmers show no tool sprite (hoe, can, sword) during tool animations.
- A joiner in the farmhouse is off-map for the others (they just disappear); the host's farmhouse state is not in the snapshot.
- Joining mid-night works (the joiner is sent in), but the joiner's clock is the snapshot's, not synced. No capacity limit beyond the relay's 4 players
  is shown in the lobby. Not tested in a browser (LineEdit on web untested).
