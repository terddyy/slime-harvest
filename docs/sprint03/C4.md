Known limits
- The systemd unit, the nginx block and `deploy.sh`'s relay upload were written but not run: no Linux, nginx or VPS here (`bash -n deploy.sh` passes). The Linux Godot binary has to be put at `/opt/godot/godot` by hand (README step 1).
- Not tested in a browser build or through wss/nginx. A web player's first connection to a dead relay can take up to 10 s before the message appears (`RelayPeer.CONNECT_TIMEOUT_MS`).
- A joiner that arrives while the host is in bed waiting for another joiner who is still loading does not change the "waiting" count; only the normal flow is handled (the host would sleep through at once if nobody else has the farm yet).
- Earlier limits still stand (no Gayle talk for joiners, ending credits pause the host's world, remote farmers have no tool sprite).
