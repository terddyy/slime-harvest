# B3: Late-game content

What changed
- Sprinklers (`scripts/sprinklers.gd`): bought at Azy for 90g once the greenhouse is restored, kept in the bag
  (`Game.sprinkler_pieces`), placed with a new hotbar tool 6 (`Player.Tool.SPRINKLER`, key `tool_6`, "Sprinkler" in settings
  and How to Play). Same placement rule as fences (grass in the farm area); Space on one picks it up. Every sunrise
  `Main._on_phase_changed` calls `Sprinklers.water_all()`, which waters the 3x3 around each sprinkler (also after sleeping).
  The tool cursor previews the 3x3. Saved as `sprinklers` (registered after `farm`) plus `sprinkler_pieces` in the game save.
  Slimes never look at them; only the hoe is blocked on their tile.
- Sheep: the pack has Sheep sheets, so one new animal (`AnimalTypes.TYPES.sheep`, 200g, max 3, gives wool for 30g, needs the greenhouse,
  shares the cows' pen). Wool has no pack icon, so it uses the new `assets/generated/late_game_icons.png`
  (`tools/gen_late_game_icons.py`, Pillow, drawn from ASCII masks; no gpt-image render). Products can name an icon `sheet`
  ("late"); `Hud.product_sheet()` picks the texture for the animal bubble, shop and inventory.
- Farm Goals: three after "saved": buy a sheep, buy/place a sprinkler (new milestone `sprinkled`), raise a flock of 3.
  `SAVED_TEXT` now reads "All goals done - enjoy your farm!".
- Shop rows are 16 px high with no gap so the 12-row right column still fits 480x270. Sprinkler row sits under the animals.
- Docs: GDD (controls, animals table, Sprinklers section, goals, ideas list), CLAUDE.md layout, ASSETS.md (sheep layout, late_game_icons).

Testing
- `run_tests.gd`: 1200 checks, 0 failed (new `_test_sprinklers`: buy rules, area, placement rules, morning watering, save/bad data;
  sheep buy rules and wool value; goals order and sprinkler/sheep goals; inventory rows with wool and sprinklers).
- Aim test passes; smoke runs (title and `main.tscn`) show only the known "resources still in use" shutdown line.
- Staged scene screenshot (2 sprinklers in a field, shop open) read at 960x540: sprinklers and wet soil visible, shop fits.
- Playthrough not run: nothing here touches the early economy, enemies or the day/night flow.

Known limits
- Sprinkler and wool art is hand-drawn pixel art, simple (the sprinkler looks like a small fountain).
- The tutorial and loading tips don't mention sprinklers or sheep.
- Wet soil from a sprinkler lasts one growth tick like normal watering, so it saves one watering per tile per day, not all of them.
- Sheep are late-game only (greenhouse is the last project), so they are not part of the 15-20 day balance path.
- Not tested in a browser build.
