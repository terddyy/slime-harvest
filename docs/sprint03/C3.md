# C3: World sync

What changed
- Model: host-authoritative. A joiner never changes the farm itself; it sends a request and the host runs the same code it runs for its own player.
- `scripts/world_actions.gd` (`WorldActions`): the tool/E/harvest logic moved out of `Player` and `Main`. Each action returns `{sfx, variation}` (plus `text/pos/color` for pickups) and plays nothing itself. Solo play calls it directly, so behaviour is unchanged.
- `scripts/coop_world.gd` (`CoopWorld`): joiner -> host RPCs `_use_tool`, `_harvest`, `_interact`, `_collect_click`, `_game_call` (sell/buy/restore, whitelisted in `CoopRules.game_call_ok`), `_sleep_state`. Host -> joiner: `_result` (sound/popup), `_farm_cell`, `_fence_cell`, `_sprinkler_cell`, `_tree_cell` (one message per changed cell, from new `cell_changed`/`changed` signals), `_game_state` (`Game.to_save()`, at most 4/s), `_clock` (1/s and on every phase change). The host only sends to joiners that already got the snapshot (`CoopSession.ready_joiners`).
- `scripts/coop_entities.gd` (`CoopEntities`): host sends slimes, animals and Gayle at 10 Hz; joiners keep `puppet` copies (`Slime`, `Animal`, `Gayle` got a puppet mode). Kills send `_slime_died` for the "+3g" popup.
- Checks on the host (pure, unit tested in `CoopRules`): known tool/seed/sapling/facing, cell within 5 tiles of where that farmer was last seen, only buy/sell/restore calls with known ids.
- Panels: `Game.set_ui_open()` replaces `get_tree().paused` in shop, board, bag, Esc menu and Gayle dialog. Online the tree is not paused and the own farmer stands still while a menu is open. `Game.is_paused()` is used where the code asked "is something paused".
- Sleeping online: bed sends "asleep", host waits for host + all joiners ("Waiting for N more...", E gets you out of bed), then `Farmhouse.sleep_through_night()` runs once and everyone wakes. Dawn also wakes everybody.
- Joiner clock: `Game` waits at 0 for the host's `_clock`; orchard growth and sprinkler watering run on the host only; joiner farm does not tick.
- Docs: CLAUDE.md layout and test command. GDD not changed (no new rules; C4 writes the Online co-op section).

Testing
- `run_tests.gd`: 1272 checks, 0 failed (new `_test_coop_world_rules`, `_test_coop_cell_sync`).
- `tests/coop_world_test.tscn` (host + joiner process + relay, 26 checks, run 3 times, green): real `Player` code on the joiner does till, water, plant, harvest, sell, buy a seed, restore the well, fence, sword on a host slime, bed; host grows the crop, breaks the fence, buys a chicken, spawns the slime. Rejected requests (far tool use, `add_gold`, unknown seed) do nothing. At the end both worlds write a signature (soil, crops, fences, gold, bags, buildings) and the host checks they are equal.
- `net_test` 40/0, `coop_test` 13/0, aim test passes, title and `main.tscn` smoke runs only print the known shutdown lines, playthrough (defend) saved the farm on day 11. A frame of the farm scene was rendered and read. All processes killed.

Known limits
- Joiners can't talk to Gayle (she follows the host); Gayle dialog is host only.
- The ending panels/credits still pause the local tree with `get_tree().paused`; on the host that pauses the world for everybody until it is closed.
- Remote farmers still show no tool sprite; slime hurt flash and sounds are host-side only (joiners get animation and the kill popup).
- A joiner who walks into the farmhouse is off-map for the others; the host's farmhouse state is not synced.
- Slimes target crops only; the spawner keeps spawning away from the host's player, not the joiners.
- Joiner purchases are optimistic (the shop shows "Bought" at once; the host answers with an error sound if it refused).
- Only localhost tested, not a browser build.
